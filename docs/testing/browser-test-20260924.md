# 浏览器功能测试包

功能代码来自 `feat/browser-multitab-control` 的 `f575d7b8d`。
打包分支 `build/browser-test-20260924` 仅关闭正式版自动更新源，防止测试包
启动后自动安装不含本次功能的正式版。应用内版本号仍为 `1.15.0`，以安装包
文件名中的功能提交号识别本次构建。此配置只用于分支测试包，不合并到正式版。

支持 Apple Silicon（M 系列）Mac。等待旧版正在运行的任务完成并退出应用后，
打开 DMG，将 NarraNexus 拖到 Applications，再从 Applications 启动。

浏览器默认无头运行。设置中可选择已安装的 Google Chrome，或安装托管浏览器；
浏览器二进制不随安装包附带。网站提示浏览器不支持或验证错误时，可手动开启
有头模式，重新启动浏览器会话后重试，登录状态保留。有头模式会出现独立浏览器窗口。

测试内容包括：Agent 打开网页免站点授权、跳转与弹窗显示多个标签页、用户切换
查看页面、接管后新建标签页和输入网址、关闭标签页，以及交回控制后 Agent 继续操作。
任意脚本执行仍有独立权限配置。测试包不提供正式版在线更新，后续通过安装包替换。
